# Apple 香港库存监控桌面版 · v4.0.1

这是 Windows 免安装桌面版的界面与监控模块源码。普通使用者从 Windows 交付包启动 EXE，不需要安装浏览器扩展，也不需要安装 Node、Python 或开发工具。桌面程序的构建与运行方式见项目根目录的说明。

## 开始使用

1. 将 Windows 免安装 ZIP **完整解压**到有写入权限的固定文件夹。
2. 双击解压后的程序 EXE。保留旁边所有文件和子文件夹，不要只移动 EXE。
3. 在“监控概览”选择商品及门店，添加到监控列表。先点击“立即检查”确认结果，再点击“开始监控”。
4. 默认每 60 秒安排检查。程序最小化或留在系统托盘时继续监控；保持电脑联网并避免休眠。关闭主窗口时，可选择留在托盘或完全退出。

顶部“打开 Apple 官网”打开程序内的官网窗口，供本人查看商品、门店或处理登录验证。此窗口使用独立会话，不共享 Chrome / Edge 的 Cookie 或登录状态。首次使用桌面版需要重新设置监控任务与通知；程序不会自动迁移旧扩展的数据。旧扩展的历史可先导出 CSV 保存。

## 数据与备份

设置、任务、历史及官网会话保存在 EXE 旁的 `Data` 文件夹。“打开数据目录”可查看实际位置。移动程序时保留整个程序目录及 `Data`，删除 `Data` 会丢失本机状态。

暂停监控并等待当前检查结束后，可点击“导出备份”，选择保存位置。导出包含配置与历史 CSV，**不包含 Apple 登录会话和 Bark 设备密钥**，也不是可以一键恢复的完整程序快照。需要完整保存本机状态时，应完全退出程序后复制整个 `Data` 文件夹；此副本可能含个人会话与设备密钥，应自行妥善保管。

普通检查保留最近 100,000 条，库存变化单独保留最近 50,000 条，达到各自上限后删除最早记录。历史页可按“全部检查”或“库存变化”导出完整保留记录，时间显示为香港时间。关闭主窗口不会删除数据。

## 频率与 HTTP 541 保护

支持 60 秒、20 秒和 10 秒模式；10 秒加速持续 10 分钟后恢复 20 秒。最多选择 8 个重点 SKU，非重点商品每 60 秒安排检查。同一 SKU 的已选门店合并查询，每批最多 8 个 SKU：例如 40 个 SKU 一轮最多分为 5 批请求，所以 60 秒并不等于整个程序每分钟只请求一次。请求耗时、异常等待和电脑休眠可能增加实际间隔。

HTTP 541、401、403、429 或异常 HTML 响应会触发持续保护性暂停。冷却结束、重启、立即检查或重新开始都不会自动绕过暂停，也不会自动反复刷新官网。Windows v4.0.1 先在程序内官网窗口完成附近门店查询，再点击“连接官网，单次验证”，仅查一款商品；浏览器版按钮为“官网恢复后，单次验证”。有效响应后仍保持暂停，需要手动“开始监控”才恢复循环。Windows 首次连接流程和升级方法详见根目录 Windows使用说明.md。

桌面化保留此保护，不能保证 Apple 的限制立即解除，也不能保证 60 秒频率始终被允许。HTTP 541 不能直接证明 Cookie 固定两小时到期。错误或受阻响应不代表无货；界面会保留上次有效结果，恢复到相同库存状态不会制造新的补货变化。

## 界面功能

| 视图 | 功能 |
|---|---|
| 监控概览 | 添加商品与门店、同 SKU 分组、搜索与状态筛选、连接状态和暂停恢复 |
| 历史与日志 | 全部检查、库存变化、CSV 导出、运行日志 |
| 频率与通知 | 10 / 20 / 60 秒、重点 SKU、实际请求间隔、Bark 配置 |
| 购买准备 | 单个准确 SKU、数量 1、价格上限、门店顺序与尝试记录 |

目录参考价不代替官网结算价。“有货”需要精确匹配门店与 SKU 的有效响应；“不可提取”“查询异常”“未开放预订”分别显示，不能解释成实际库存数量。

## Bark 与购买准备

Bark 默认关闭。在“频率与通知”中保存设备密钥或 `https://api.day.app/设备密钥` 后启用，支持发送一次测试通知。服务器受理不代表手机已经收到，请在手机上确认。密钥保存在本机，不回填明文，不进入运行日志、历史、诊断或 CSV。

首次有货或明确库存变化后重新有货时提醒，持续有货不重复通知；发送失败或送达未知不会自动重发。已启用时，连接与购买准备事件各自去重。

自动加入购物袋默认关闭，需要指定完整 SKU、最高单价及允许门店，数量固定 1。只有明确有货、购物袋可核实为空、商品与价格均匹配时才尝试。已有购物袋商品不会自动改动，遇到登录、验证码、页面改版或不明确结果会停止并等待本人处理。每款商品的尝试会记录，避免后台重启或重复事件重复加入。

加入购物袋不代表锁定库存或订单成立，最终商品、门店、配送、价格、付款与下单仍由本人确认。真实 Apple 页面兼容性与长时间运行应按本次交付包的验收说明确认。

## 源码验证

在本目录安装开发依赖后运行：

```powershell
npm install
npm test
npm run check
```

或使用 `pnpm install --frozen-lockfile`、`pnpm test`、`pnpm run check`。测试使用模拟 API 与本地响应，不发起真实 Apple 加购或 Bark 推送。JSDOM 测试覆盖实际 HTML 与界面逻辑，不等同于真实 Windows 窗口布局或 Apple 会话验收。桌面主进程与打包检查见根目录说明。
