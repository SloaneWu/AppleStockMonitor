# Windows v4.0.1 · 预发布

适用于 Windows 10 / 11 x64，提供免安装版。完整解压后双击 `AppleStockMonitor.exe`，请保留 EXE 旁的全部文件。

**已知未解决问题：用户反馈连续监控约两小时后再次出现 HTTP 541，具体在用版本与设置待确认。根因尚未确认，本次发布不表示这一问题已根治。** 程序发生受阻时会持久暂停，详见 [已知问题](https://github.com/SloaneWu/AppleStockMonitor/blob/main/docs/KNOWN_ISSUES.md)。

## 本版改动

- 首次连接先被动观察程序内官网的门店服务响应；页面未就绪、加载失败或官网已受阻时不追加监控请求。
- 连接与恢复改为单款商品验证，同款所选门店合并，成功后仍需手动开始监控。
- 新增脱敏诊断导出，记录有限的响应状态、类型、时间及查询计数；不导出 Cookie、响应正文或 Bark 密钥。
- 保留任务、历史、暂停保护，以及托盘运行和独立官网窗口。

## 安装与升级

首次使用：添加商品与门店，在程序内打开官网并查询附近门店，再返回点击“连接官网，单次验证”。验证通过后才开始循环监控。

从旧版升级：完全退出旧程序，将新版解压到新文件夹，把旧 EXE 旁整个 `Data` 文件夹复制到新 EXE 旁，保留旧目录备份。不要同时运行两版。`Data` 可能含个人会话和通知密钥，不应分享或上传仓库。

## 已完成与尚未完成的验证

v4.0.1 历史验收中，183 项模块测试和 11 项 EXE 离线检查通过。EXE 自检使用真实 Windows / Electron 窗口、IPC 和存储，但 Apple / Bark 外部网络关闭，库存为模拟响应。

这些结果没有验证 Apple 实时库存、连续运行稳定性、登录或购买页面兼容性，也没有验证 Bark 手机实际收件。连续两小时后的 541 已有复现反馈，仍需受影响会话的诊断及对应修复验证。
